# FunEvents

FunEvents is a ticket sales system prototype. Its architecture proposal and prototype documentation are maintained in the `Documents` folder.

## Documentation

- [System architecture proposal and prototype design](Documents/DESIGN.md) — describes the proposed system architecture for FunEvents and the technical prototype, including its API, reservation expiry worker, and simulated payment flow.
- [Local environment setup](Documents/SETUP-LOCAL-ENVIRONMENT.md) — explains how to run the system locally, including PostgreSQL, the API, the reservation expiry worker, and the console client through .NET Aspire. It also covers running the backend projects individually.

Start with the design document for the architecture and prototype scope. Use the local setup guide for prerequisites, configuration, and run instructions.
